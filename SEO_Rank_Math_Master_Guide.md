## 📌 Executive Summary & Rank Math 75+ Checklist

To achieve a **75+ / 80+ Green Score** in Rank Math on every single page, ensure each element in this guide is populated in the Rank Math Meta Box in WordPress:

1. **Focus Keyword:** Paste the exact Focus Keyword provided for each page into Rank Math's "Focus Keyword" field.
2. **SEO Title:** Copy and paste the provided SEO Title. It has been strictly optimized:
   * Contains the Focus Keyword right at or near the beginning.
   * Between 50 and 60 characters (fits Google's 580px mobile/desktop limit).
   * Contains numbers ("2026-27", "29+", "5-Step") for a **+10 Title Readability boost**.
3. **Meta Description:** Copy and paste the Meta Description. It contains the Focus Keyword and a strong Call-to-Action (150–160 characters).
4. **URL / Permalink:** Verify the permalink matches the exact slug specified in this guide.
5. **Image Alt Attribute:** For at least one featured or primary image on that page in WordPress (Media Library or Gutenberg image block), set the **Alt Text** to the exact keyword-rich string provided in this guide.
6. **Subheadings (H2 / H3):** Ensure the recommended H2 or H3 heading appears within the content.
7. **Content Links:**
   * **Internal Link:** At least 1-2 links to other school pages (e.g., link to `/admissions/` or `/contact/`).
   * **External Link:** At least 1 link to an authoritative external domain (e.g., [cbse.gov.in](https://www.cbse.gov.in) with `rel="noopener noreferrer"`).
